# Video uploads (mp4, mov, webm)

**Reported by Boss:** an `.mp4` upload was refused as "file not supported".

## Three separate gates, all closed

1. **No video type existed in the allowlist** (`internal/files/sniff.go`) — the map only knew images,
   PDF, DOCX/XLSX, text, and zip.
2. **Go cannot sniff mp4.** `http.DetectContentType` answers `application/octet-stream` for every ISO base
   media file, so even an allowlisted `video/mp4` could never be detected from bytes. Added `sniffVideo`:
   an `ftyp` box at bytes 4..8 (brand `qt  ` → mov, otherwise mp4, with a `.mov` name deciding generic
   brands) and the EBML magic `1A 45 DF A3` → webm.
3. **The picker filtered video out.** `Composer.vue`'s `accept` list had no video entries, so on Android the
   file chooser hid `.mp4` before any upload was attempted.

Also: a single 25 MB ceiling applied to everything. A video is not a document — `maxVideoBytes = 64 MB` now
applies to video, 25 MB still applies to documents, and the per-type rule is enforced *after* sniffing.

## UI

Video attachments render in place with `<video controls playsinline preload="metadata">` (no 40 MB download
before playing — the server already answers Range), with the filename and size underneath.

## Verified live, end to end

```
ffmpeg test clip         94 518 bytes, "ISO Media, MP4 Base Media v1"
upload  → HTTP 201       {"mime":"video/mp4","size":94518,"sha256":"f80ddfc9…"}
stored   → video/mp4     94 518 bytes, name iris-test.mp4
download → 200           Accept-Ranges: bytes, Content-Type: video/mp4
range    → 206           Content-Range: bytes 0-1023/94518
attach to a message → Hermes called vision_analyze on the clip
```

## Open item, Hermes-side, not Iris

`vision_analyze` on a 6-second mp4 started and had not returned after ~9 minutes; the turn was stopped
manually. Iris delivered the file correctly (the tool ran, the path was valid) — what Hermes does with a video
is its own behaviour. Worth a follow-up: framing the room contract so Hermes extracts frames with ffmpeg first
instead of handing a video to a still-image tool.

## Tests

Six new cases in `internal/files/sniff_test.go`: mp4 by brand (`isom`, `mp42`, `M4V `), mov by brand (`qt  `)
and by extension, webm by EBML magic, and text renamed to `.mp4` **not** mistaken for video. 13 Go packages ok;
70 web tests; typecheck clean.
