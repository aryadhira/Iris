## Endpoints

| Method | Path | Auth | Behaviour |
|---|---|---|---|
| GET | `/api/health` | no | `{ok:true, version:"0.1.0-p1a"}` |
| POST | `/api/auth/login` | no | `{passphrase}` → HttpOnly cookie; wrong → 401 + 250 ms |
| GET | `/api/auth/me` | cookie | `{authenticated:true}` |
| POST | `/api/auth/logout` | cookie | deletes the row, clears cookie |
| POST | `/api/rooms` | cookie | `{name, topic}`; Hermes session first, then row; Hermes failure → 502 with no row |
| GET | `/api/rooms` | cookie | active rooms, newest first |
| GET | `/api/rooms/{id}` | cookie | one room |
| POST | `/api/rooms/{id}/archive` | cookie | sets `archived_at`; idempotent |
| GET | `/api/rooms/{id}/messages?before=<RFC3339>&limit=50` | cookie | newest first, cursor strictly older, limit capped at 200 |
| POST | `/api/rooms/{id}/messages` | cookie | `{text}` → SSE `delta` / `tool` / `done` / `error` / `unknown`; persists user then assistant |

The room JSON deliberately omits `hermes_session_id`; it stays server-side.

## What is missing

- No UI; P1 still needs the Vue shell, room list, composer, streaming bubble and reload test.
- No continuation pump, run timeline, artifacts, voice, search, notifications or export.
- Room rename is not exposed (only archive); the schema supports it later.
- In-flight assistant text lives in memory until the Hermes stream ends. A hard kill of `irisd` loses that
  partial turn; the user message is already durable.
- The detached turn has no overall cap by design; only the 90 s idle watchdog bounds a silent Hermes.
- Login is rate-limited only by the fixed 250 ms delay; there is no IP/device throttle or CSRF token.
- `IRIS_COOKIE_SECURE` defaults to false for loopback; HTTPS/Tailscale cookie hardening is P5.
- No auto-migrate at boot; `irisd` checks for the schema and tells you to run `migrate`.

## Most likely to break

The 90 s idle watchdog versus real long-running Hermes work. Keepalive comments deliberately do **not** count as
activity (a stalled run must not look like work), but if Hermes goes more than 90 s with neither `tool.*` nor
`assistant.*` events during a long terminal job, `irisd` will end the turn with the honest
"Hermes went quiet…" error and keep the partial text. That threshold is the first thing to watch in P3.

## Start it

```
cd ~/Documents/projects/iris
~/go/bin/migrate -path db/migrations \
  -database 'postgres://lab:labdev@127.0.0.1:5432/iris?sslmode=disable' up
IRIS_DATABASE_URL='postgres://lab:labdev@127.0.0.1:5432/iris?sslmode=disable' \
IRIS_PASSPHRASE='<owner passphrase>' \
go run ./cmd/irisd
```

The key is read from `~/.config/iris-api-key` at boot and never printed. Health: `curl http://127.0.0.1:3300/api/health`.
